# Ubuntu Food Truck — Sample Website

This is a **free sample website** built for Ubuntu Food Truck by [Clementine Web Co.](https://clementinewebco.com), a small web design studio based in St. Petersburg, FL. It's not live yet and isn't an official Ubuntu Food Truck website — just a preview of what one could look like.

## What's in this repo
A simple, framework-free website:
- `index.html` — the page content
- `styles.css` — all styling
- `script.js` — small interactive touches (menu, scroll effects, the contact form)

No build tools, no installs — open `index.html` in any browser to view it, or visit the live preview at **https://dljackson97.github.io/ubuntu-food-truck/**.

## About the content
Photos, menu items, prices, the weekly schedule, and reviews shown here are placeholders standing in for the real thing — they'll be swapped for Ubuntu Food Truck's actual photos, menu, and details if this moves forward. The catering/event contact form is wired up but not yet fully activated.
